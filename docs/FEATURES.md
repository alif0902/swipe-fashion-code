# HITOME — 機能一覧（モバイルWebアプリ）

コードから拾った実装済み機能。管理画面（PC）は末尾に別掲。
下部ナビは5つ: **フィード / 探す / 一目惚れ / バッグ / マイページ**

---

## 1. フィード `/feed` — 中核

| 機能 | 内容 |
|---|---|
| 一着表示 | 画面いっぱいに1商品だけ。カテゴリー階層も検索窓もなし |
| 右スワイプ | マッチ演出 → 購入シートへ。`like` として記録 |
| 左スワイプ | 見送る。`pass` として記録（学習に使われる） |
| 「いいね！」ボタン | 一目惚れに保存。`super` として記録（重み +3） |
| マッチ演出 | 右スワイプ時のオーバーレイ。2秒で自動的に閉じる |
| 上スクロール | 基本情報（素材・採寸・評価）がせり上がる。ページ遷移なし |
| 初回チュートリアル | 3段階の視覚ガイド。実際の商品写真で左右の動きを示す |
| 好みの学習 | 直近5スワイプから profile を組み立て、並び順に反映 |

**重み** — いいね！ +3 ／ 右 +1 ／ 左 −1
**評価軸** — カテゴリー ×3 ／ ブランド ×2 ／ 色 ×1.5 ／ 価格帯 ×1

---

## 2. 探す `/lookbook` — カタログ

| 機能 | 内容 |
|---|---|
| 性別タブ | レディース / メンズ |
| カテゴリー絞り込み | タブ切り替え |
| 並び替え（FAB） | 新着順（既定）／ 価格が安い順 ／ 価格が高い順 |
| URL連動 | 絞り込みはクエリ文字列。ブックマーク可・戻るボタンが効く |

**検索窓は意図的に置いていない。**「おすすめ順」も外してある — 好み順はフィードの仕事であり、
カタログの並べ替えの一つとして見せると誤解を招くため。

---

## 3. 一目惚れ `/obsessed` — お気に入り

- 保存した商品のグリッド表示
- 各商品から購入シートへ直行
- **削除ボタン**（バッグと同じ操作感で統一）

---

## 4. バッグ・注文 `/orders`

**購入シート（`order-sheet`）**

| 機能 | 内容 |
|---|---|
| サイズ選択 | 在庫のあるサイズのみ |
| **サイズガイド** | その場で開く早見表。身長・胸囲（ボトムスはウエスト）から S/M/L を選べる。表示されるのはその商品が実際に販売しているサイズだけ。レディース／メンズで数値も切替 |
| カラー選択 | 実際の写真からサンプリングした色見本 |
| 数量・合計 | — |

**決済シート（`payment-sheet`、デモ）**
クレジットカード ／ PayPay ／ コンビニ払い ／ Apple Pay ／ 代金引換

**注文管理**
- 注文一覧、確定、キャンセル、削除
- 在庫は注文と同一トランザクションで引き当て（同時注文でも売り越さない）

---

## 5. レビュー `review-sheet`

- 商品カードの「評価」行をタップして開く
- 星の分布 ＋ 実際の着用コメント（上位3件、続きは展開）
- **誰でも投稿できる**（星・ニックネーム・本文500字）
- 投稿すると評価は加重平均で即更新、自分の投稿には「あなた」バッジ
- 本文はプレーンテキストとして描画（スクリプト挿入経路なし）

---

## 6. マイページ `/account`

| 項目 | 内容 |
|---|---|
| **足あと** `/footprints` | 判断した一着すべてを新しい順に |
| **いいね！履歴** `/likes` | 気になった一着だけを抽出 |
| 一目惚れ / バッグ | 各ページへの導線 |
| **お届け先** `/account/edit` | プロフィール編集 |
| アバター | アップロード＋**削除** |
| 管理画面リンク | 管理者ロールのときだけ表示 |

---

## 7. 全体にかかる機能

| 機能 | 内容 |
|---|---|
| **匿名のまま全機能** | 会員登録なしでスワイプ・保存・注文まで可能 |
| **履歴の引き継ぎ** | 登録した時点で、それまでの匿名セッションの履歴を移行（`lib/claim.ts`） |
| 認証 | メール＋パスワード（Better Auth）。認証シートはモーダル |
| **PWA インストール** | ホーム画面に追加。Chrome/Android は1タップ、iOS Safari は手順を案内（`beforeinstallprompt` が無いため） |
| スプラッシュ | 起動画面 |
| 通知（トースト） | 画面上部・時間制限つき・残り時間バー付き。閉じるボタンは常時表示（タッチ環境ではホバーが効かないため） |
| 商品詳細 `/product/[id]` | 単体ページ。フィード外からの共有・直リンク用 |
| 商品写真 | 2枚組（1枚目モデル着用、2枚目単品） |

---

## 管理画面（PC）`/admin`

- ダッシュボード：**商品ごとの「いいね率」**（いいね＋一目惚れ ÷ 全スワイプ）を、見送られた回数が多い順に
- 商品の一覧・新規登録・編集
- **写真の切り抜き**：フィードのカードと同じ縦3:4の枠で表示範囲をその場で調整（出力 1080×1440 JPEG）
- 権限はページとサーバー処理の両方で毎回検証。役割はセッションの控えではなくDBから直接読む
